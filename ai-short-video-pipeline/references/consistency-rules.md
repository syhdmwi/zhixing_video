# Consistency Rules

这个参考文件用于控制“同一人物、同一风格、同一条视频”的稳定性。

## 1. Build Three Immutable Blocks First

在写任意单镜头提示词之前，先固定以下三块：

### Character Block

至少写清：

- 性别表现
- 年龄段
- 脸型
- 五官特征
- 发型与发色
- 身材与身高感
- 主服装
- 常驻配饰
- 身份气质

如果有真人参考图，优先基于参考图归纳，而不是凭空扩写。

### Style Block

至少写清：

- 画面质感，例如电影感、广告写真、纪实抓拍、插画
- 光线类型
- 色彩倾向
- 镜头语言
- 景别偏好
- 时代/空间背景
- 画面清晰度与细节级别

### Negative Block

至少约束：

- 人脸漂移
- 发型或服装漂移
- 多手指、肢体畸形
- 五官不对称
- 多余人物入镜
- 背景主体抢戏
- 低清晰度、糊脸、局部崩坏

## 2. Keep Global Blocks Stable Across All Shots

单镜头提示词中允许变化的是：

- 动作
- 机位
- 场景
- 道具
- 表情
- 前后景关系

默认不应变化的是：

- 主角身份
- 核心脸部特征
- 发型和主服装
- 总体风格
- 色彩语言

## 3. Prefer Reference Anchors When Available

如果模型支持参考图、一致性角色、固定 seed 或风格锁定，优先使用。这个 skill 不假设具体参数名，但应该在输出中提醒用户：

- 同一角色尽量复用同一参考图组
- 同一批次尽量复用同一风格基底
- 先通过静帧确认一致，再批量扩镜头

## 4. Reduce Variation Per Shot

一个镜头建议只引入一到两个变量变化，例如：

- 只换机位，不换服装和时代背景
- 只换动作，不换人物身份和场景基调
- 只换表情，不换整体光影方案

不要在单镜头里同时大幅改变：

- 年龄
- 妆造
- 服装主色
- 发型
- 空间时代感

## 5. Motion Comes After Still-Frame Approval

图生视频前先确认静帧：

- 主角脸没有漂
- 服装和道具没有错位
- 风格延续正确
- 构图适合运动

如果静帧不稳，不要直接继续加复杂动作。

## 6. Multi-Character Scenes

多人场景要先给每个角色独立标识，例如：

- `Character A`
- `Character B`
- `Narrator Avatar`

并分别固定他们的外观和服装主设定，避免角色互相串脸。

## 7. Space Consistency（空间一致性）

人物三视图解决「人物长什么样」，空间锁定卡解决「场景怎么排布」。两者互补，缺一不可。

### What The Spatial Lock Controls

空间锁定卡约束的是镜头之间的空间连贯性：

- 环境锚点（墙壁、窗户、家具、设备）的位置不能在镜头之间跳变
- 光线方向必须前后一致，不能上一个镜头光从左来、下一个镜头光从右来
- 人物站位不能超出空间锁定卡定义的范围
- 轴线不能跨越：如果人物在窗户左边，下一个镜头不能突然跑到窗户右边（除非有明确的走动过渡）

### How To Apply

每个镜头的 image_prompt 都必须继承：

1. 人物三视图的外貌约束（Character Block）
2. 空间锁定卡的环境锚点和光线方向
3. 风格模板的质感参数（Style Block）
4. 该镜头自己的动作和构图变化

提示词写法示例：

```
[Character Block: 男主外貌描述...]
[空间锁定: 场景A的环境锚点和光线方向...]
[Style Block: 风格参数...]
本镜头：中景，男主坐在桌前揉太阳穴，电脑屏幕光打在脸上，构图偏左，右侧留空给环境锚点（窗户）。
```

### Common Failure Modes To Prevent

- 场景内物体位置跳变（窗户从左跑到右）
- 光线方向反转
- 人物站位超出合理范围
- 同一场景出现不同空间布局（AI「自动清洁」bug）
- 轴线越位导致空间逻辑混乱

### When Spatial Lock Conflicts With Story

如果文案里明确要求场景变化（例如从室内走到室外），这是合理的场景切换，不是空间不一致。此时：
- 新场景用新的空间锁定卡
- 不同场景之间的切换不需要保持空间一致性
- 同一场景内的镜头必须保持空间一致性

## 8. Quality Review Loop（质量审核回环）

一致性规则不是只在写提示词时检查，生成结果后也要回检。所有静帧和视频生成完成后，必须经过质量审核回环才能进入下一阶段。

审核内容与本文件 §1-§7 一一对应：
- §1 三块不变量 → 角色一致性检查
- §2 全局块稳定 → 风格一致性检查
- §3 参考锚点 → 参考图与生成结果对比
- §4 减少变量 → 构图多样性检查
- §5 静帧优先 → 运动中人脸稳定性检查
- §6 多角色 → 角色区分度检查
- §7 空间一致性 → 环境锚点和光线方向检查

详细审核维度、严重程度分级和输出格式见 [quality-review-loop.md](./quality-review-loop.md)。
