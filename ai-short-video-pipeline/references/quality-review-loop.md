# Quality Review Loop（质量审核回环）

## Overview

质量审核回环是在图片/视频生成完成后、进入下一阶段之前的自动一致性检查步骤。它的目的是在用户手动检查之前，先由系统主动发现明显的质量问题，减少用户逐张排查的负担。

## When To Trigger

- 全部静帧图片生成完成后、展示给用户确认之前
- 全部图生视频生成完成后、进入剪辑之前
- 数字人视频生成完成后、进入剪辑整合之前

不在以下阶段触发：
- 三视图阶段（数量太少，用户自己能看）
- 单张修改重生成（已有针对性检查）
- 纯文字提示词阶段（还没有视觉产出）

## Review Dimensions

### 1. Character Consistency（角色一致性）

检查项：
- 脸型、五官比例是否前后一致
- 发型、发色是否漂移
- 服装主设定是否变化
- 配饰是否丢失或变化
- 年龄感是否前后不一致
- 肤色是否漂移

检查方式：
- 逐张对比 Character Block 描述
- 相邻镜头之间的人物外观对比
- 首尾镜头的人物外观对比（防止渐变漂移）

### 2. Spatial Consistency（空间一致性）

检查项：
- 同一场景内环境锚点位置是否跳变（窗户从左跑到右）
- 光线方向是否反转
- 人物站位是否超出空间锁定卡定义范围
- 轴线是否越位
- 同一场景是否出现不同空间布局

检查方式：
- 同一场景内的镜头分组对比
- 对照空间锁定卡的环境锚点和光线方向
- 检查轴线连续性

### 3. Style Consistency（风格一致性）

检查项：
- 画风是否前后一致（写实 vs 插画 vs 动漫）
- 色彩倾向是否漂移
- 光影类型是否一致
- 画面质感是否突变
- 时代/空间背景是否冲突

检查方式：
- 对照 Style Block 描述
- 首尾镜头风格对比
- 相邻镜头风格对比

### 4. Composition Variety（构图多样性）

检查项：
- 是否连续多张都是同一景别（全是半身 or 全是远景）
- 是否连续多张都是同一机位角度
- 人物镜头和纯场景镜头比例是否合理（约 2:1）
- 是否存在构图疲劳（连续多张几乎一样的构图）

检查方式：
- 统计景别分布
- 统计机位角度分布
- 统计人物/场景比例
- 检测连续相同构图

### 5. Artifact Detection（瑕疵检测）

检查项：
- 是否出现多余手指、肢体畸形
- 五官是否不对称
- 是否有文字、水印、logo 意外出现
- 是否有多余人物入镜
- 是否有低清晰度、糊脸、局部崩坏
- 背景是否出现不合理的物体融合

检查方式：
- 逐张检查 Negative Block 约束是否被违反
- 对比原始提示词是否有意料外元素

## Output Format

审核结果按以下格式输出：

```
质量审核报告

总镜头数：[N]
审核通过：[M] 张
需关注：[K] 张

## 需关注的镜头

### Shot [ID] — [问题类型]
- 问题描述：[具体说明哪里不一致]
- 严重程度：🔴 必须修改 / 🟡 建议修改 / 🟢 轻微可忽略
- 建议操作：重生成 / 局部修改 / 可接受

### Shot [ID] — [问题类型]
...

## 整体趋势
- [描述是否存在整体性问题，如渐变漂移、风格偏移等]

## 建议
- [整体建议，如"建议先修正 Shot 3、7、12 后再进入视频阶段"]
```

## Severity Levels

🔴 **必须修改**：严重影响角色辨识度或空间逻辑的问题
- 角色串脸（变成了另一个人）
- 场景空间完全错乱
- 风格突变（写实变卡通）
- 肢体严重畸形

🟡 **建议修改**：不完美但不影响整体连贯性
- 服装细节微变
- 光线方向有轻微偏差
- 构图略单调
- 配饰偶有缺失

🟢 **轻微可忽略**：用户可能注意不到的小问题
- 色温略有差异
- 背景细节不同
- 景别略有变化

## Integration With User Flow

审核完成后：

1. 如果没有 🔴 问题：直接展示审核报告 + 图片，询问用户是否满意
2. 如果有 🔴 问题：先展示审核报告，建议用户先处理必须修改的镜头，再展示图片
3. 如果 🔴 问题 ≥ 30%：建议整体重生成该批次

推荐话术：

```text
质量审核完成：
- 总共 [N] 张图
- [M] 张通过
- [K] 张需要关注

其中必须修改的有 [J] 张：
- Shot [ID]：[问题摘要]
- Shot [ID]：[问题摘要]

建议先修正这些问题，再进入视频阶段。
需要我自动重生成这些问题镜头吗？输入 1 自动重生成；输入 2 先看全部图片再决定。
```

## Auto-Retry Rules

当用户选择自动重生成时：

- 只重生成 🔴 级别的镜头
- 重生成时保留原始提示词，但追加针对问题的修正指令
- 重生成后再次运行质量审核
- 最多重试 2 轮；如果 2 轮后仍有 🔴 问题，交给用户手动处理

## Limitations

质量审核回环是「辅助检查」，不是「自动修复」。以下情况仍需用户判断：
- 主观审美偏好（"这个构图不好看"）
- 文案理解偏差（"这个画面不符合我想表达的意思"）
- 品牌调性不符（"这个颜色和品牌色不搭"）
- 情绪表达不对（"这个表情太严肃了"）

审核回环只负责检查「客观一致性」，不替代用户的审美判断。
