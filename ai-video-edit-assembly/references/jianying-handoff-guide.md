# Jianying Handoff Guide

本指引只覆盖路线 B：手动导入。交付包提供规范素材、`timeline.csv`、`subtitles.srt` 和 `delivery-manifest.json`，不写入剪映草稿目录，也不依赖剪映私有草稿字段。

## 交付包内容

- `timeline.csv`：镜头顺序、起止时间、轨道、素材文件、转场、BGM 标记。
- `subtitles.srt`：标准 SRT 字幕，可通过剪映字幕导入功能载入。
- `delivery-manifest.json`：交付摘要、轨道统计、素材清单和生成脚本信息。
- 素材文件：建议按 `shot_id` 命名，例如 `shot_01.mp4`、`shot_01.wav`。

## Windows 导入步骤（剪映国内版）

1. 新建草稿：打开剪映国内版，创建新项目，确认画幅和项目帧率。
2. 批量导入素材：将交付包内的视频、音频、BGM、图片素材一次性导入媒体库。
3. 按 `timeline.csv` 排轨：按 `order` 从小到大放置素材，`avatar` 放主讲人口播或配音占位轨，`broll` 放画面轨。
4. 处理覆盖关系：口播信息段优先保证字幕和音频清晰；B-roll 覆盖画面时不要遮挡关键信息。
5. 导入 SRT 字幕：进入文本或字幕导入功能，选择 `subtitles.srt`，导入后检查字幕起止时间。
6. 添加 BGM/转场：按 `bgm_note` 和 `transition` 标记添加音乐、音效和转场，优先使用轻量转场。
7. 导出检查：全片预览一遍，确认字幕、素材顺序、口型同步和封面 CTA 后再导出。

## Mac 导入步骤（剪映国内版）

1. 新建草稿：打开剪映国内版 Mac 版，创建新项目，设置画幅和项目帧率。
2. 批量导入素材：把交付包素材拖入媒体区，保持原文件名，便于对照 `timeline.csv`。
3. 按 `timeline.csv` 排轨：按镜头顺序拖入时间线，`avatar` 轨用于主讲人口播或配音占位，`broll` 轨用于画面素材。
4. 处理覆盖关系：需要主讲人口型的段落放在可见上层；解释图、界面、对比图作为 B-roll 覆盖或穿插。
5. 导入 SRT 字幕：使用字幕导入入口选择 `subtitles.srt`，检查中文编码、换行和时间码。
6. 添加 BGM/转场：按 `timeline.csv` 的 `bgm_note` 与 `transition` 列处理，避免转场打断口播节奏。
7. 导出检查：导出前确认总时长、字幕、音量、封面和平台比例。

## 轨道约定

- `avatar`：主讲人口播或配音占位轨，优先保证口播信息、字幕和主体稳定。
- `broll`：解释图、界面录屏、概念图、数据对比、场景补充画面。
- 覆盖原则：B-roll 可覆盖旁白段，但不要覆盖需要观察主讲人口型或手势的关键段。

这一路线跨剪映版本更稳定，因为它只依赖公开 UI 导入能力和通用文件格式。
