# Image To Video Prompt Rules

这个文件定义“已确认静帧图片 -> 图生视频提示词”的生成规则。

目标不是做大动作炫技，而是稳定地让静帧里的主体自然动起来，同时保持：

- 人物不串脸
- 服装不乱变
- 场景结构不漂移
- 画风不跳变

## 1. Core Principle

纯图生视频阶段，默认优先级如下：

1. 保持首帧构图和人物外观稳定
2. 保持画风稳定
3. 让主体产生小幅、合理、可控的动作
4. 再考虑镜头运动

不要先追求复杂动作，再去补稳定约束。

## 2. Prompt Structure

每条 `video_prompt` 默认按这个结构组织：

```text
[主体动作]
[次要环境动作]
[镜头运动]
[风格保持]
[负面约束]
```

不要只写“让它动起来”。必须同时写：

- 谁在动
- 动多大
- 怎么动
- 哪些不能变

## 3. Motion Types

每个镜头默认先判断一个 `motion_type`：

- `讲述型`
- `展示型`
- `情绪型`
- `场景型`
- `冲突型`

### 讲述型

适合：

- 主讲人出镜
- 人物面向镜头表达观点
- 采访感、解说感镜头

默认动作：

- 轻微点头
- 极小幅抬手或手臂自然位移
- 肩膀和上半身细微呼吸感
- 视线稳定

镜头建议：

- 轻微推近
- 轻微左右漂移

### 展示型

适合：

- 机器人讲解
- 道具展示
- 图表、设备、吉祥物演示

默认动作：

- 轻微转头
- 手臂小幅抬起
- 道具或屏幕有轻微响应
- 保持站位稳定

镜头建议：

- 轻微推近
- 小幅横移

### 情绪型

适合：

- 思考
- 犹豫
- 压迫感
- 沉默停顿

默认动作：

- 眼神细微变化
- 头部轻微下沉或抬起
- 呼吸感
- 姿态变化极小

镜头建议：

- 轻微推近
- 轻微后拉

### 场景型

适合：

- 办公室
- 会议室
- 法庭
- 实验室
- 城市场景

默认动作：

- 主体少动或不动
- 环境里有极轻微活动感
- 屏幕光、纸张、视线或群体姿态有轻微变化

镜头建议：

- 缓慢横移
- 缓慢推近
- 缓慢后拉

### 冲突型

适合：

- 对峙
- 辩论
- 强对比
- 情绪峰值

默认动作：

- 动作幅度可以比其他类型大一点
- 但仍然要限制在“真实的小幅动作”范围

镜头建议：

- 明显一点的推近
- 小幅环绕感

默认不要全片大量使用冲突型。

## 4. Motion Intensity

每个镜头再判断一个 `motion_intensity`：

- `low`
- `medium`
- `high`

默认规则：

- 全片默认 `low`
- 重点镜头可用 `medium`
- `high` 只在用户明确要求时才使用

### low

- 轻微点头
- 轻微呼吸
- 极小幅手部变化
- 镜头缓慢移动

### medium

- 较明显的抬手
- 更明确的转头
- 更清楚的镜头推进

### high

- 更强表演性
- 更明显的身体动作
- 更强镜头运动

默认不推荐。

## 5. Default Safe Rules

每条提示词默认都应附带这些稳定约束：

- 保持人物脸型、五官、发型、服装、身体比例不变
- 保持场景结构和主要道具不变
- 保持原始插画/渲染风格不变
- 不要新增人物
- 不要新增肢体
- 不要突然切换成写实照片风
- 不要大幅改变机位
- 不要出现闪烁和背景漂移

## 6. Model-Friendly Writing Rule

图生视频提示词应短、明确、能执行。

优先写：

- small natural head movement
- slight breathing motion
- subtle hand gesture
- gentle camera push-in
- keep face and outfit unchanged

不要写成大段散文式描述。

## 7. Default Duration Rule

默认单镜头时长：

- `4` 到 `5` 秒

如果镜头是讲述型或情绪型，优先：

- `4` 秒

如果镜头是展示型或场景型，优先：

- `5` 秒

## 8. Review Rule

在真正提交图生视频前，每条镜头至少应能回答这 5 个问题：

1. 谁在动？
2. 动作幅度多大？
3. 镜头怎么动？
4. 哪些元素保持不变？
5. 这条视频是低风险还是高风险？

如果答不出来，说明提示词还不够可执行。
